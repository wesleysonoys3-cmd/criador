# f10-qa Three

Jogo 3D (corrida3d) gerado pelo **Game Studio** do Tiagente usando Three.js.

## Como executar
- Abra `index.html` no navegador, ou
- Use o botao **Pre-visualizar** no Game Studio.

## Controles
- WASD ou setas para mover; ESPACO para pular. Clique na tela para reiniciar apos o fim.

## Tecnologia
- Three.js 0.149.0 (licenca MIT) — https://threejs.org
- Geometrias/materiais gerados em tempo de execucao: nenhum recurso externo de imagem/som.
