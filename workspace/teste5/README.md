# 🛍️ StiloVibe — Loja de Roupas Moderna

Site de vendas de roupas e acessórios moderno, responsivo e totalmente interativo desenvolvido com HTML5, Tailwind CSS e JavaScript vanilla.

## 🚀 Funcionalidades Principais
- **Catálogo Dinâmico:** Produtos organizados por categorias (Masculino, Feminino, Acessórios) com preços, fotos e descrições.
- **Filtros e Busca em Tempo Real:** Filtre instantaneamente por categoria ou busque pelo nome da peça.
- **Carrinho de Compras Interativo:** Drawer lateral deslizante com controle de quantidade, cálculo automático de subtotal e frete.
- **Sistema de Cupons:** Utilize o cupom **`STILO10`** para ganhar 10% de desconto no carrinho.
- **Modal de Detalhes:** Visualização ampliada do produto com seletor de tamanhos (P, M, G, GG, etc.).
- **Checkout Simulado:** Tela de finalização de pedido rápida e intuitiva.
- **Design Moderno:** Utiliza Tailwind CSS e ícones FontAwesome, garantindo alta performance e visual profissional.

---

## 🛠️ Como Executar

Basta abrir o arquivo `index.html` diretamente em qualquer navegador moderno ou utilizar um servidor local (como a extensão *Live Server* do VS Code).

Ou via terminal (Node.js):
```bash
npx serve .
```
