# Fase5 QA

Jogo 2D (tiro) gerado pelo **Game Studio** do Tiagente usando Phaser 3.

## Como executar
- Abra `index.html` no navegador, ou
- Use o botao **Pre-visualizar** no Game Studio.

## Controles
- Setas (ou A/D) para mover; ESPACO (ou seta ↑) para pular/atirar conforme o genero.

## Tecnologia
- Phaser 3.80.1 (licenca MIT) — https://phaser.io
- Texturas geradas em tempo de execucao: nenhum recurso externo de imagem/som.
